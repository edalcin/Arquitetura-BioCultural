# Governança dos dados

## Quem decide

A **comunidade detentora do conhecimento**. Cada Unidade Federada guarda seus dados, e quem decide sobre eles é quem os detém.

## O que decide

- o que se registra;
- o que se publica, e para quem;
- o que se retira, a qualquer momento.

Essas decisões valem registro a registro. A arquitetura não decide por ninguém.

## Estado atual, com honestidade

**Ainda não há comunidade com voz direta nesta governança.** Hoje a conversa acontece pelo Ponto-Focal da iniciativa UseFlora, que representa a iniciativa, e não as comunidades. As perguntas que só as comunidades podem responder estão registradas como questões no GitHub, com a etiqueta `para-comunidades`. Elas esperam um caminho para chegar até as comunidades.
