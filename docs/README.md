# Documentação da Arquitetura BioCultural

Toda a documentação fica nesta pasta, em três partes. Quem chega agora deve começar por
[`../ComecePorAqui/`](../ComecePorAqui/README.md).

| Pasta | Para quem | O que tem |
|---|---|---|
| **[Governanca/](Governanca/README.md)** | Participantes da governança e interessados | A proposta de governança em três camadas; uma pasta por camada (dados, ferramentas, arquitetura); as reuniões de governança da arquitetura, com pautas, resumos e impactos; a pauta das comunidades |
